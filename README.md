# morse-translator

- Это мой проект для колледжа.

- Переводчик текста в азбуку Морзе и обратно.

- Поддерживает русский язык. (и возможно английский язык, если дойдут руки)

## Схема работы, коротко:

    Русский → Морзе

    Морзе → Русский

    Графический интерфейс (tkinter)

## Как запустить:

1. Установи Python 3.10+
2. Склонируй репозиторий: git clone ...
3. Запусти: python morse.py

## Требования
- Python 3.10+
- tkinter (встроен)

## Что не умеет
- Не поддерживает цифры и знаки препинания
